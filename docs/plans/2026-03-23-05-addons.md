# Subsystem 5: Add-ons (FR-024)

## Overview
Configurable add-on services per bathhouse (веники, напитки, полотенца, etc.) with per-item/per-hour/per-person pricing. Integration with booking flow for add-on selection and total calculation.

## Context
- Existing booking flow: `internal/service/booking_service.go`, `internal/handler/booking_handler.go`
- Booking model: `internal/domain/booking.go` — has TotalPrice, discount fields
- Price calculation in service layer during booking creation
- Bathhouse model: `internal/domain/bathhouse.go`
- Prices in kopecks (int64)

## Dependencies
- No dependencies on other new subsystems
- Booking Enhancements (Subsystem 7) will integrate add-ons into extended booking flow
