# Subsystem 14: Cron Jobs & Background Tasks

## Overview
Centralized cron scheduler consolidating all periodic tasks from other subsystems. Uses robfig/cron or similar library, registered as an fx module.

## Context
- No centralized cron system exists currently
- Various subsystems define periodic tasks:
  - Wallet: bonus expiration, expiry notifications
  - Booking: request timeout, no-show detection, reminders
  - Review: auto review requests
  - CRM: auto-scenario execution
  - Search: saved search notifications
  - Auth: account deletion, session cleanup
  - KYC: expiry checks
  - Escrow: matured escrow release
  - Anti-fraud: pattern detection
  - Owner: response rate monitoring
- Existing fx setup: `internal/app/` — Uber fx DI container

## Dependencies
- Depends on ALL other subsystems (calls their services)
- Should be implemented LAST after all services are in place

## Development Approach
- **Testing approach**: Regular (code first, then tests)
- **CRITICAL: every task MUST include new/updated tests**
- **CRITICAL: all tests must pass before starting next task**
